# AI-Powered Telegram Chatbot using n8n & Google Gemini

🚀 **Project Overview**  
A fully automated **Telegram Chatbot** built using **n8n workflow automation**, **Google Gemini LLM**, and **persistent memory**. This system supports multi-user interactions, secure authorized-user mode, and context-aware conversations with minimal coding.

---

## 🌟 Features

- AI responses powered by **Google Gemini LLM**  
- Chat support for **unlimited users**  
- **Authorization-based private chatbot** for approved users  
- **Memory-enabled conversation flow** for context awareness  
- **Real-time message processing** through Telegram triggers  
- **Modular and reusable workflow design**  

---

## 🧠 Workflow Architecture

### 1. Multi-User Chatbot
- **Telegram Trigger** → Captures user messages  
- **AI Agent → Gemini LLM** → Generates AI responses  
- **Simple Memory Node** → Maintains conversation context  
- Automated messaging for seamless interaction  

### 2. Authorized-User Chatbot
- **User validation logic** → Checks approved users  
- **Unauthorized notification** → Alerts users if access is denied  
- **Response only after approval**  
- **AI-assisted chatting with memory** for personalized experience  

---

## 🧩 Technologies / Nodes Used

- **n8n Cloud**  
- **Telegram Trigger / SendMessage**  
- **Google Gemini Chat Model**  
- **AI Agent Node**  
- **Simple Memory Node**  
- **Authorization Logic (Switch + IF nodes)**
